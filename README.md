# 球坐标 · 让 sin θ 看得见

一个**零依赖单文件网页**，用 Canvas 2D 手写三维投影，把球坐标系里那些"看不出来的量"画出来：
`r sin θ` 到底量的是哪一段、为什么体积元里偏偏多一个 `r² sin θ`、同一个 `4πr²` 积分怎么在刚体、
电磁、热学、量子四个领域反复出现。

## 打开方式

下载 `index.html` 后双击，或启用 GitHub Pages 后直接访问仓库首页。

## 页面内容

### 1. 主视图
拖动 P 点或用滑块改 `r / θ / φ`，右侧实时给出直角坐标、`sin θ`、`r sin θ`（P 到 z 轴的距离）与纬线圈半径。
空白处拖动可旋转视角，滚轮缩放。

### 2. 体积元放大镜
把 P 点附近的体积元固定比例放大，三条棱分别是 `dr`、`r dθ`、`r sin θ dφ` ——
`sin θ` 只挂在 φ 这一条棱上，这就是 `dV = r² sin θ dr dθ dφ` 的来源。

### 3. 物理情景（8 个 tab）

| tab | 情景 | 真正在变的东西 |
|---|---|---|
| A1 | 球壳转动惯量 | φ 被积掉，只剩 θ 扫环带（θ=180° 时 `J/mR² = 2/3`） |
| A2 | 高斯定理 + 撒点 | 面积元 `r² sin θ`；θ 均匀撒点会在两极挤成一团，cos θ 均匀才处处一样密 |
| A3 | 麦克斯韦速率分布 | 同一个 `4πv²`，半径换成速率；T 翻倍三个特征速率全乘 √2 |
| A4 | 圆锥摆 | r、θ 不变，只有 φ 在跑；但 `a_θ ≠ 0`，因为 `e_θ` 自己也在转 |
| B1 | 均匀带电球壳 | 按 r 分段：壳内 E=0，壳外与点电荷完全一致 |
| B2 | 开普勒椭圆 | 同一时间内扫过的两块扇形面积相等 |
| B3 | 1s / 2p 电子云 | 径向概率 `r²|R|²`：1s 峰在 a₀，2p 峰在 4a₀ |
| C | 纬度 ↔ 极角 | 不是物理情景，是最常见的换算错：`θ = 90° − λ` |

## 约定

- **配色语义固定**：蓝 = 径向 `r`，青 = `θ` 方向（经线），橙 = `φ` 方向（纬线圈）。
- 所有读数都在页面里实时计算并在底部对照表里给出理论值，便于自查。
- 动画默认暂停，每个情景各有独立复位按钮；相机俯仰角被限制在 17°–72°，避免转到退化视角看不出立体感。

## 技术说明

- 单个 HTML 文件，无 CDN、无构建步骤、无第三方库。
- 三维部分是自己写的正交投影（`camBasis` + `projectPt`），按深度分档控制线条透明度。
- 画布按 `devicePixelRatio` 适配，支持高 DPI 屏幕与浏览器缩放。
